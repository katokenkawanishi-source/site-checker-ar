====================================================
現場チェッカーAR（重機・車両・高さ制限対応版）使い方
====================================================

■ フォルダ構成
  index.html                 ... メイン画面
  models/                    ... 3Dデータ(.usdz)を入れるフォルダ
    ├─ height_barriers.usdz  ... 3段階高さ制限バリア（既存データを入れてください）
    ├─ 25t_rafter_crane.usdz ... 25tラフタークレーン
    ├─ 10t_truck.usdz        ... 10tトラック
    ├─ 30t_lowboy_trailer.usdz ... 30t低床トレーラー
    ├─ 20t_trailer.usdz      ... 20tトレーラー
    └─ models_list.js        ... 自動認識用のモデル一覧ファイル
  update_models.bat          ... 【Windows用】ダブルクリックでmodelsフォルダ内のUSDZを自動登録

■ 新しいUSDZデータを追加する手順（2通りの方法）

【方法A】Windowsでダブルクリックするだけ（一番簡単・確実）
  1. 「models」フォルダの中に、新しい .usdz ファイルを入れます。
  2. 「update_models.bat」をダブルクリックします。
  3. 自動的に models/models_list.js が書き換わり、アプリを開くと選択肢が増えています。

【方法B】Webサーバーの自動検出を使う場合
  Apache / Nginx / Python簡易サーバー等のディレクトリ一覧が有効な環境では、
  modelsフォルダに .usdz を入れるだけでページ読み込み時に自動検出されます。
  ※GitHub Pages や Netlify などの静的ホスティングを使う場合は、アップロード前に
    【方法A】の update_models.bat を1回ダブルクリックしてからアップロードしてください。

■ 日本語ファイル名もOK
  例：「models/0.7m3バックホウ.usdz」のように日本語ファイル名で入れても、
  そのまま「0.7m3バックホウ」という選択肢として自動表示されます。
